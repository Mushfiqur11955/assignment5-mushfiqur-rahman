## Description of the project
FoCar is a small robot car made with a Raspberry Pi Pico.
It has two DC motors, a motor controller, wires, and batteries to make the car move.
The car can move forward, backward, left, and right.

## User instructions 
First, connect the Raspberry Pi Pico to the motor controller using the correct wires.
Then connect the two DC motors to the motor controller and make sure all the connections
are secure. Connect the 4 AA battery pack to provide power to the car.

Connect the Raspberry Pi Pico to the computer using a USB data cable (USB-B). Upload the
Python program to the Raspberry Pi Pico and start the program. The car will automatically
move forward, turn left, move backward, turn right, and then move forward again according
to the programmed timings.

Before running the car, make sure the DC motors, motor controller, Raspberry Pi Pico,
4 AA batteries, power connections, and wires are connected correctly. Keep the car on
a clear surface and make sure there is enough space for it to move safely.
